## 📝 Overview
**My Digital Dairy** is a modern, full-stack portfolio built with **Flask**. It showcases projects, skills, and allows visitors to contact me directly through a sleek, responsive interface. The site is fully theme-aware, supporting both light and dark modes with a clean glassmorphism design.

---

## ⚡ Features
- Dynamic **Projects** section powered by Flask and Jinja templates.
- **About** section detailing expertise and tech stack.
- **Skills** section with animated skill cards using HTML, CSS, and JS.
- **Theme toggle**: light & dark modes with CSS variables.
- Fully **responsive design** for all devices.
- **Contact form** with backend support for sending messages.
- Social media buttons linking to **GitHub** and **LinkedIn**.

---

## 🛠️ Tech Stack
- **Backend**: Python, Flask
- **Frontend**: HTML5, CSS3, JavaScript
